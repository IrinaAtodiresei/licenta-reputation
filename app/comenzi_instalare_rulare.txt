============================================================
REPUTATION DASHBOARD – GHID INSTALARE WINDOWS
============================================================

Acest ghid explică toți pașii necesari pentru a instala și rula
aplicația Reputation Dashboard pe Windows, inclusiv instalarea
Torch CPU, Transformers, Streamlit și toate dependențele.

------------------------------------------------------------
1. INSTALARE PYTHON 3.10
------------------------------------------------------------
1. Descarcă Python 3.10 de aici:
   https://www.python.org/downloads/release/python-3100/

2. La instalare, BIFEAZĂ:
   [x] Add Python to PATH

3. După instalare, verifică:
   CMD → scrie:
   python --version
   Trebuie să apară:
   Python 3.10.x

------------------------------------------------------------
2. DESCARCĂ PROIECTUL
------------------------------------------------------------
1. Clonează repo-ul sau descarcă ZIP-ul.
2. Deschide folderul proiectului în Windows Explorer.
3. Deschide CMD în acel folder:
   Shift + Right Click → "Open PowerShell window here"
   sau
   scrie în bara de adresă: cmd

------------------------------------------------------------
3. CREARE MEDIU VIRTUAL (venv)
------------------------------------------------------------
În CMD:

python -m venv venv
venv\Scripts\activate

Promptul trebuie să arate așa:
(venv) C:\...\ReputationDashboard02>

------------------------------------------------------------
4. INSTALARE TORCH CPU (IMPORTANT!)
------------------------------------------------------------
Torch NU se instalează din requirements.txt.
Trebuie instalat manual cu index-ul oficial PyTorch.

Rulează:

pip install --upgrade pip
pip install torch==2.2.0+cpu torchvision==0.17.0+cpu torchaudio==2.2.0+cpu --index-url https://download.pytorch.org/whl/cpu

Verificare:
python -c "import torch; print(torch.__version__)"
Trebuie să apară:
2.2.0+cpu

------------------------------------------------------------
5. INSTALARE DEPENDINȚE PROIECT
------------------------------------------------------------
Rulează:

pip install -r requirements.txt
python -m nltk.downloader vader_lexicon

------------------------------------------------------------
6. CONFIGURARE SECRETS (opțional)
------------------------------------------------------------
Dacă folosești PostgreSQL sau Groq:

Creează folderul:
.streamlit

Creează fișierul:
.streamlit/secrets.toml

Exemplu:

DB_HOST = "host"
DB_PORT = "5432"
DB_NAME = "dbname"
DB_USER = "user"
DB_PASSWORD = "password"
GROQ_API_KEY = "cheia-ta"

------------------------------------------------------------
7. RULARE APLICAȚIE
------------------------------------------------------------
Din CMD (cu venv activ):

streamlit run app/streamlit_app.py

Aplicația se va deschide în browser:
http://localhost:8501

------------------------------------------------------------
8. PROBLEME FRECVENTE
------------------------------------------------------------

1) Eroare: "torch not found"
   → Torch nu a fost instalat corect.
   Reinstalează cu comanda din pasul 4.

2) Eroare: "sentencepiece not found"
   → Rulează:
     pip install sentencepiece

3) Eroare: "vader_lexicon not found"
   → Rulează:
     python -m nltk.downloader vader_lexicon

4) Eroare: "model not found"
   → Prima rulare descarcă modelul NLP (~500MB).
     Așteaptă finalizarea.

------------------------------------------------------------
INSTALAREA ESTE COMPLETĂ!
