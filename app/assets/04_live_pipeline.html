Academic interpretation

This live demonstration shows the operational flow of the application on a small Reddit sample. The same logic used in the main dashboard is reproduced in a faster, temporary pipeline: Reddit data is collected, comments are extracted, each comment is associated with one of the three companies, and sentiment is computed using Logistic Regression, VADER, and a Transformer-based model.

From an academic perspective, this tab illustrates how data collection, entity mapping and multi-model sentiment analysis can be orchestrated into a reproducible pipeline.
